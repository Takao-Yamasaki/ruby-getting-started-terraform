【実行内容】
計画中 (コメントアウト) リソースを追加した draw.io 構成図を再作成

追加した計画中リソース:
- プライベートサブネット (RDS): 192.168.21.0/24 (ap-northeast-1a), 192.168.22.0/24 (ap-northeast-1c)
- RDS MySQL 8.0.41 (db.t3.micro, 20GB gp3)
- Secrets Manager (RDS認証情報)
- S3 Bucket (RDSバックアップ, 365日ライフサイクル)
- Lambda Function (rds_s3_export, Python 3.11)
- KMS Key (RDSバックアップ暗号化)
- EventBridge Rule (Lambda起動スケジュール, 毎日13:00 JST)

- 通常表示 = 有効なリソース
